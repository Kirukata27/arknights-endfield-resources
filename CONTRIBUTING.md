# Contributing

Thank you for your interest in improving this community resource!

## What we need

- **Tier list updates** after new patches — open an issue with the proposed changes
- **New operator entries** when Hypergryph adds characters to the game
- **Corrections** to pity mechanics or banner rules if the game updates them
- **Team composition examples** for new content or challenges

## How to contribute

1. **Open an issue first** — describe what's outdated or missing
2. **Fork the repo** and make your changes on a new branch
3. **Submit a pull request** with a clear description of what changed and why

## Guidelines

- Keep information accurate and up-to-date with the current patch
- Link to official sources when citing game mechanics
- Do not include game assets (images, audio, etc.)
- English only for consistency

## Data sources

Live operator stats are synced automatically from [ReEnd Database](https://reend.vallov.com/) via the daily workflow. Manual edits to `data/stats.json` will be overwritten on the next sync.

For full build guides, skill breakdowns, and tier analysis, visit **[reend.vallov.com](https://reend.vallov.com/)**.
