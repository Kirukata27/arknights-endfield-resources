## Pity & Banner Mechanics

### Character Banners (Chartered / Basic Headhunting)

| Pull # | Event |
|--------|-------|
| 1–65 | Base 6★ rate: **0.8%** |
| 66+ | Soft pity: rate increases **+5% per pull** (0.8% → 5.8% → 10.8%…) |
| **80** | **Hard pity: guaranteed 6★** |
| Every 10 | Guaranteed **5★ or higher** |

**Key rules:**
- Pity counter **carries over** between Chartered (limited) and Basic Headhunting (standard) banners
- On limited banners, each 6★ has ~**50% chance** to be the featured operator
- Unlike Genshin/HSR, losing the 50/50 does **NOT** guarantee the next pull is featured
- After **120 paid pulls** on the same limited banner: Rate-Up Guarantee (next 6★ = featured)
- After **240 paid pulls** on the same banner: additional Potential Token reward

### Arsenal Exchange (Weapon Banner)

| Pull # | Event |
|--------|-------|
| 1–30 | Base 6★ weapon rate: base |
| 31+ | Soft pity kicks in, rate increases per pull |
| **40** | Hard pity: guaranteed any 6★ weapon (25% chance = featured) |
| **80** | Guaranteed featured 6★ weapon |
| Every 10 | Guaranteed **5★ weapon or higher** |

**Key rules:**
- Weapon banner pity **resets each new Arsenal Exchange issue** (does not carry over)
- Arms Offering milestones are **cumulative across all issues**: at 100, 180, 260… pulls total
- Arms Offering alternates between: Standard 6★ selector → Exclusive featured weapon

## Beginner's Checklist

**Early game priorities:**
- [ ] Complete main story to unlock all banner types
- [ ] Pull on the Beginner banner (cost-reduced, guaranteed 6★ at 50 pulls)
- [ ] Unlock and use Potential system to improve dupe operators
- [ ] Prioritize upgrading your main DPS skill to Level 7+
- [ ] Unlock gear set crafting and equip 4-piece sets on your 6★ roster
- [ ] Use **Arms Offering** milestones — cumulative pulls give free weapons
- [ ] Enable pity tracking before pulling so you never lose count

**Team composition basics:**
- Standard meta: 1 Main DPS + 1 Sub DPS + 1 Supporter + 1 Defender
- Prioritize applying **Vulnerable** before your DPS deals damage
- Combo Skills activate after using a Skill — sequence order matters significantly
